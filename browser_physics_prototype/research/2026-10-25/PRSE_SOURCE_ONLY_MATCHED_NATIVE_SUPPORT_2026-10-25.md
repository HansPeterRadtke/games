## Truly matched native physical input and method alternatives

A CPU-pretrained spaCy English dependency parser used only original source text, original frozen noun mentions and earlier frozen open-vocabulary noun candidates. It proposed 76 ON relationships across 47 original source descriptions; 73 fell within accepted native scenes. It did not load official author relation annotations and did not supply generated object coordinates.

Three physical alternatives were compared over EXACTLY the same 197 accepted source scenes, preserving the identical original prose, actual GameCore/Rapier implementation and every one of the 2,048 source-linked nonwall rigid bodies in the broad open-vocabulary materialization:

- CONTROL: prior frozen native scene with generic object placement. Eleven actual native object-object contact pairs.
- DETERMINISTIC LEXICAL: original frozen source ON relationship proposals plus exactly the same bounded non-overlap and top-surface placement code, with up to eight placements per scene. Fifty candidate relationships considered, zero new admissible placements, eleven native contact pairs.
- PRETRAINED SOURCE-ONLY: noun-chunk source ON proposals from already frozen grammatical parse, same placement code and bounded attempts. Seventy-three candidate relationships in accepted scenes, eighteen physically and geometrically admissible new placements over thirteen independently source-selected scenes. All eighteen became genuine native Rapier collider contact pairs after physics, yielding twenty-nine actual contact pairs.

Every physical attachment was proposed from a source-text relationship with original token offsets, required unique child/support physical instances, a movable child, an available sufficiently sized support footprint and an overlap-free three-dimensional position, then passed actual GameCore native physics stepping and trusted whole-world/contact/ID source save/reentry. All 197 accepted source scenes retained identical entity counts and passed later native saving. Unsupported object types, non-unique references, preexisting support and inadequate surface dimensions were explicitly refused; no author annotation was used to choose a coordinate. All new open-vocabulary physical objects nevertheless remain provisional small collision boxes with unverified real size, shape, material, articulation and affordance.

Only the strict preflight v4/v5 results are used for the claim in this report; the original v1-v3 negative outputs remain archived.

## Practical owner decision and remaining falsifiable work

Pretrained source relation structure plus deterministic physical feasibility and native contact checks can improve physically realized author-intended support on a constrained existing source dataset at exactly the same body budget, whereas repeating the lexical placement pass added none. This justifies keeping the source-relationship model as a PROPOSAL stage, not allowing it to overwrite original author truth or physical authority.

The general PRSE target is STILL FAR from proven. Eleven out of 354 author ON source requirements are supported, ten new physically contacting pairs were not author-annotated, nearly all gains occurred in partly assisted rather than human source examples, and many required source object kinds/quantities/realistic physical sizes are still missing. Generic box colliders do not provide true furniture geometry, container interiors, support affordances, character articulation or believable scenes. Current text is accurate cautious factual change prose, not independently validated expressive literary rewriting; unscripted offscreen society and general cross-region physical continuity remain open.

Next work capable of changing the conclusion must use NEW independent original human literary source descriptions, reliable instance/reference and quantity scope, an approved searchable/generative three-dimensional asset catalog with metric/collider/support metadata, and source-only physical constraint proposals. Real GameCore support/contact validation and subsequent observer/story reentry must be scored separately from source author meaning and writing quality. Do not claim nominal AABB top potential, new physical bodies or fluent-looking model paragraphs prove the original author world.
