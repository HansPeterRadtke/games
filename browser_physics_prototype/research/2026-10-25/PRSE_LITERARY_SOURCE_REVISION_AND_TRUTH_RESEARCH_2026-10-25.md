## Why separate current physical truth from literary prose?

Published research supports this separation. Ruoyao Wang and colleagues, “Can Language Models Serve as Text-Based World Simulators?”, ACL 2024 (https://aclanthology.org/2024.acl-short.1/), evaluated action/state prediction in text games and found GPT-4 unreliable as a standalone world simulator. Rachelyn Farrell and Stephen Ware, “Large Language Models as Narrative Planning Search Guides”, IEEE Transactions on Games, 2025, DOI 10.1109/TG.2024.3487416, used symbolic planning to constrain narrative paths while LLMs guide the search. These are independent scientific references, not measured results for this PRSE implementation.

Our question was more basic than literary model eloquence: can an existing verified GameCore/Rapier world produce a truthful, observer-specific, persistent textual account without mistaking the old literary source description or a model proposal for present-world fact?

## New research-sidecar semantic revision layer

The new research-only source revision adapter wraps the SAME authoritative PRSELoop/GameCore/Rapier physical world, existing physically grounded source-relation evidence and the previous event-time Rapier observer. It does not implement a separate text-only simulated world.

Historical source prose is retained byte-for-byte as an archive with a source checksum. The adapter never blindly republishes this original as current physical truth. Each current relation must be measured from unique real physical object IDs, current support/contact and geometrical facts, and the observer must actually be able to see the objects. A witnessed physical event requires an event-time observation, not a later guess about what probably happened.

The output is a bounded append-only semantic revision record: source-indexed, entity-identified verified relationship changes; actual already witnessed physical event sequence IDs; and separately visible current object-state descriptions. Each revision retains world time and its evidence type. The adapter suppresses duplicate unchanged text on subsequent reads, with separate knowledge journals per observer. Unsupported or ambiguous source claims are withheld, not promoted to prose.

This is deliberate factual English, not a fluent generative novelist. It does not modify original source style, infer implied characters or unknown motives, or rewrite full paragraphs; it creates an auditable current factual overlay while preserving the source as historical text.

The research save transaction binds the whole existing native Rapier world to GameCore semantic state, source text and relation digests, previously delivered factual claims, observer-specific witnessed event sequences and the current revision ledger. Restore checks source identity, clock, event sequence, physical entity references, native solver and journal integrity together. The format is owner-trusted and build-bound, not suitable for arbitrary untrusted external saves or live multi-region server replacement.

## First corpus experiment: an important omitted current-world fact

The same sixty-three previously frozen external SceneEval descriptions with independently materialized dynamic 3D objects were evaluated, with genuine GameCore impulses and physically ray-verified observers. The source/geometry parameters and physical actions were held fixed; there was no new user skill teaching, corpus fine-tuning or new large-model call.

The initial new adapter correctly delivered sixty-three witnessed physical impulses, no hidden causes to distant observers and no duplicated statements after physical-plus-narrative save/reload. But it produced only forty-three initial verified relation statements and **forgot to forward newly visible object-state descriptions**. This was a genuine failure not caught by simple event/identity checks.

The failure surfaced in a direct original-recording-driven offscreen paper-fire example. A real paper note rested on a wooden desk; the observer left; an explicitly authored semantic combustion rule updated the note offscreen; the note’s stable identity became a semantic tombstone; and a separately linked thin real ash rigid-body collider materialized on re-entry. GameCore correctly described the ash, and the physical observer confirmed it visible, but the combined literary output was empty.

The original result is preserved as the negative file prse_source_revision_omitted_visible_ash_negative_v1.json with actual body count, ray visibility, core description and missing adapter text. No claim of physically simulated thermochemistry is made.

We corrected the adapter to forward new, physically visible object-state facts, with direct current object ID, any origin/tombstone ID, world time and actual perception evidence. Relationship statements take precedence when describing the same principal object to prevent obvious duplication. In the original owner-inspired fire case, the visitor now hears only the truthful aftermath, “ash from old warning paper remains at this location.” The visitor is NOT told the unseen ignition cause. A second read, and a further native world-and-narrator re-entry, produce no duplicated text. Original prose and original destroyed note remain preserved.

## Exact same corpus after the correction

The first sixty-three-case source-derived result was NOT overwritten. A second exclusive-create run used the same source IDs, geometry proposals, physical action vectors, observation method and native save/reload policy. It completed all sixty-three scenes again.

The corrected adapter produced four hundred and four initial factual sentences: three hundred sixty-one physically visible current-object-state descriptions and forty-three physically verified source-relationship descriptions. Actual later physical interactions produced forty-six further object-state descriptions and seven verified relation changes. All sixty-three originally visible impulse events were observed at their authoritative occurrence time and subsequently delivered to the appropriate observer. Remote observers received zero hidden impulses. Unchanged text was not repeated after a normal read or a combined native physical-plus-semantic save. Original source text/IDs remained unchanged in all sixty-three. Each subsequent physical intervention after the native save preserved the tested source relation truth, with no source-object position deviation above two centimetres; maximum observed difference was approximately 0.000635 metres.

The numerical sentence count is NOT a measure of engaging literary quality. It measures limited factual coverage of a known 3D scene. All content still depends on the source parser, physical shape data, observer approximation and explicit event/relationship facts. The prior source-meaning failures are not improved merely by describing more generic physically present objects.

## Joint physical/source/observer transaction checks

One selected human-written SceneEval lamp/nightstand scene was used as an independent physical-causality and serialization control. After a real observed physical impulse, the trusted transaction restored the native world, source archive, observer witness ledger and current semantic changes together. Nine intentionally altered source/clock/handle/native-data cases and one rehashed invented authoritative event were rejected. A valid save retained already observed event sequences without repeating them; one additional real GameCore physical impulse after saving produced no measured position difference against the uninterrupted reference.

These are useful internal trusted-state consistency checks, NOT a proof that any adversary cannot fabricate a completely consistent alternative save after recomputing all hashes.

## Second negative result: source snippets usually cannot be edited as literary sentences

A critical question is whether the earlier interpreter’s sourceText excerpts can be used to patch original literary prose safely. This was independently audited across the full five hundred already frozen SceneEval source descriptions, using both the deterministic parser and its pretrained CPU syntax-union proposals. No official gold annotations entered this procedure, and original source texts were never rewritten.

The deterministic relation graph contains one thousand seventy proposed relation excerpts. Each occurs literally in the source, but only **nine** excerpts equal a complete sentence under a conservative sentence-boundary approximation. After additionally requiring a unique source and target mention, only one relation per sentence and no obvious conditional, negation or quotation, just **two** excerpts remained for manual editing review.

The syntax-union graph contains one thousand five hundred fifty-seven proposed relation excerpts. One thousand four hundred eighty-one appear as literal substrings of the corresponding source; sixty-nine match complete sentence boundaries; only **eleven** remain as potential review candidates with the same conservative requirements.

None of those thirteen total candidates is PROVEN safe to replace. A source excerpt may still carry uncertain pronouns, scope, implicit relationships and narrative voice. Blind string substitution can corrupt unrelated prose even when the physical state of one relationship is known. This directly explains why merely storing a source text span alongside a real contact event is insufficient for the owner’s desired automatic back-and-forth literary rewriting. A genuine semantic/discourse representation and independently verified constrained generation are required.

The complete original source-derived text and per-relation excerpts from this audit remain only in owner-private Nitro research storage. Git contains aggregated measurements and SHA-256 evidence, not the third-party prompt corpus or any model wheel.

## Unresolved PRSE scope and honest conclusion

The concrete achievement is a **verified research boundary**: one authoritative 3D GameCore world produces physically supported observer-specific textual changes, source-linked event and object histories, truthful offscreen aftermath, and transactionally persistent knowledge. A physically present ash remnant no longer disappears from text; unwitnessed causes remain unwitnessed; previously sent unchanged facts are not repeated.

What remains outstanding is the defining **literary** part of PRSE: a world whose current primary semantic/literary representation itself can be coherently revised at large scale with stable references, correct conditional/negation scope, sources and character perspectives, open-ended asset relationships, material damage, unknown offscreen actors and multiple interacting regions. The current historical prose plus structured revision journal is NOT equivalent to a fully rewritten, independently meaningful living literary world. A matched capable-model versus deterministic narration experiment on frozen physically verified before/after state with source-entailment, causal-privacy and literary-quality scoring remains necessary; spare production model capacity was not verified, so no shared inference was used. No fabricated human literary preference test is claimed.

The important external references for future experiments are ACL 2024 state-simulation reliability and IEEE Transactions on Games 2025 symbolic/LLM hybrid planning described above. Both suggest keeping physical/symbolic causality authoritative while treating language-generation output as a constrained, rejectable proposal.
