## A surprisingly strong negative result: apparent perfection by construction

The original frozen PRSE text interpreter extracted 2,787 object mention spans across all 500 SceneEval descriptions. Only 736 carried an explicit parsed quantity; 2,051 were unquantified mentions. Three hundred descriptions mentioned one or more noun/object types repeatedly, without demonstrating whether those expressions referred back to the same persistent object or distinct instances. The original parser aggregates repeated mentions primarily by the maximum seen quantity per type, which is not general literary reference resolution.

We reused exactly 200 previously frozen original external descriptions: the first 100 human-authored scenes and the systematic sample IDs 100,104,...,496 from the partly assisted remaining 400. No new text parser training or annotation-driven scene selection. The same real GameCore/Rapier physics and physical layout were run and their saved state independently restored.

One hundred ninety-seven scenes materialized as valid 3D worlds; three failed physical geometry acceptance. The 197 accepted worlds contained 938 actual non-wall rigid-body entities and 844 type-count proposals. Every one of the 844 parser-proposed numerical constraints matched the corresponding physically generated population, and 197/197 native GameCore saves preserved the original literary source, rigid-body IDs and counts. Physical impulses did not spuriously create extra object identities.

**That is circular self-consistency, NOT source meaning fidelity:** the engine was instructed by the parser to create those exact counts.

Six hundred seventy of the 672 mismatches were undercounts: the compiled scenes simply lacked objects required by the source annotation. Another 19 count claims belonged to the three physical scenes that could not be instantiated and were held out of the satisfaction ratio. Agreement with the text parser's proposed count was identically 565 author clauses; making those proposals physical did not repair the language interpretation.

The same external labels recorded 972 appearance/material/size attribute clauses in the accepted scenes. Only **139** matched an attribute extracted by the frozen lexical parser, including 76/264 original human annotations and 63/708 assisted annotations. These are text-only matches. The existing compiler may set an engine material field such as wood from the same parsed adjective, but doing so cannot independently verify the object's real appearance, color, physical composition or artwork. None of those 972 attributes was independently checked through measured appearance or physics in this study, so the research code explicitly withholds that claim.

Six explicit source object-absence requirements in the accepted sample were correctly parsed and physically realized. Their success does not repair the much larger quantity and attribute failures.

## Scene-level uncertainty and source-reference limitations

Four thousand seeded nonparametric scene-level bootstrap resamples, not individual correlated object labels, gave a human sample observed count agreement of about 61 percent, conditional 95 percent interval about 55.8–66.9 percent, and assisted agreement about 35 percent, conditional interval about 31.3–39.2 percent. This is variation on a curated and previously partially inspected benchmark, not a population estimate for every novel literary world. Source-label completeness and category taxonomy must also be considered.

The frozen parser had 171 repeated-type quantitative claims in the accepted physical sample. They cannot be safely promoted to exact original literary instance counts by a one-to-one kind-to-body mapping. The new source quantity evidence retains each original source mention offset, explicit versus implicit count, negation and inequality, while marking reference identity and exact globally exhaustive count entailment UNKNOWN. All currently materialized native type counts are independently measured but always explicitly scoped to the generated region, never claimed as a complete global inventory of the story universe.

## Causal negative tests, explicitly distinguished from the external sample

A selected original human SceneEval scene explicitly says there is NO coffee table. Its actually materialized world contains none, so the source absence is physically supported. While the world is unloaded, the source-count projection correctly changes live physical-count verification to UNKNOWN, while preserving source identity and offscreen semantic records. Saving the unloaded world and rematerializing the exact native objects restores physical verification of absence.

An independently authored counterfactual physically inserts one actual coffee-table collider into that room while leaving the original historical literary source unchanged. The source absence becomes FALSE and the current region text correctly acknowledges the physical table, rather than secretly rewriting the historical claim to pretend it had always been there. Native GameCore saving preserves that disagreement; the test is not misrepresented as a new independent human SceneEval experiment.

The separately authored original-owner PRSE paper/desk/offscreen-fire example begins with a real counted paper note on a wooden desk. After legitimate offscreen semantic combustion and an actual native save/reentry, the note's original ID is a destroyed historical tombstone and a distinct ash remnant has its own real physical collider. The current physical count of notes changes from one to zero; the ash is counted as a different physical kind; current text identifies the ash and original destruction without claiming that the absent observer saw ignition. The old source paragraph remains historical instead of being reused as a false present-tense count.

## Limits and what would actually answer the owner

The central PRSE blocker remains general **source meaning**: correctly identifying referents, quantifier scope, source absence/negation, indefinite examples, conditional clauses, object counts, relationships and intrinsic physical attributes in unrestricted literary descriptions. The world now distinguishes a parser proposal from observed native 3D truth and independently annotated literary evidence. It still does not infer the intended room correctly in many cases.

A meaningful next experiment should freeze completely new unseen source scenes; compare a capable source-aware semantic model with the earlier deterministic and pretrained grammatical parsers; separately evaluate correctly grounded instance counts, quantified reference chains, negative and conditional scope, actual 3D geometry, contact and source entailed attributes, and only then permit constrained natural-language literary rewrites. Every model-generated new statement must remain a rejectable proposal until verified by native GameCore physical truth, original source provenance and observer knowledge. No production LLM/GPU model was used or interrupted here and no human acceptance result was invented.
