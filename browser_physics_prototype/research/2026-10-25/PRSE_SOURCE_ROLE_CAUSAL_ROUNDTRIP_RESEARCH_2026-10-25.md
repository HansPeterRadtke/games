## Why this is an independent and more difficult problem than object counts

The prior frozen external SceneEval sample has serious source understanding and spatial coverage failures. Generic noun proposals and 1,110 additional actual small Rapier boxes improved category-count coverage from 565 to 972 of 1,237 annotated constraints, but author source object-object relations barely changed: only 18 original, 33 generic, 18 strict-catalog of 512 source-relation types our current physical predicates can even test. Crucially, only three author-annotated "on" relations were actual native contact-supported in any arm. Simply making source noun tokens into real colliding objects does not preserve the literary scene.

A separate known problem is more subtle: the existing source parser can misread "a magazine lies on the sofa" as a VASE resting on that sofa if several nouns occur in the same source clause. GameCore can then create a perfectly REAL physical vase/sofa support whose semantic origin is false. A physical truth query cannot reverse this history and prove what the original prose intended. The necessary test is SOURCE-role interpretation independently of PHYSICAL-contact validation, then their combined causal and narrative continuation.

## Experiment A: source syntax is evidence, not a physical fact or complete entailment

A conservative source-blind pretrained grammatical guard was developed for original "on" proposals. It uses the already installed official pretrained CPU spaCy en_core_web_sm 3.8 dependency parser on the exact previously frozen source prose, preserving literal source spans and source relationship IDs. No author SceneEval annotation gold was read by the guard. It approves only a limited explicit child–preposition–support syntactic attachment, and abstains from ambiguous "on the right side", part-of/side/top, mixed-subject, mismatched head noun, unsupported inverse or unresolvable PP roles. This is a source-side heuristic with NO model hallucinated action, no inferred exact coreference, no guarantee that annotators fully listed each relation.

Across the same original 200 sampled external SceneEval descriptions, the parser extracted **54** object "on" propositions. The source-only grammatical gate approved **nine** and withheld **45**. A separate existing real GameCore/Rapier materialization audit evaluated 53 such proposals in physically accepted scenes: **27** were physically TRUE, 11 FALSE and 12 UNKNOWN. Only eight were in the specifically predeclared narrow eligible class of UNIQUE movable child, UNIQUE sufficiently large target support, no child dependencies and real native physical support. All eight were ALREADY true, so there was no room for safely improving those particular placements by another local solver sweep.

An independent source author ON-type annotation scorer was invoked ONLY after those source-only and native physical outputs were frozen. Of the original 54 extracted "on" relations, **11** agreed with an independently annotated source TYPE PAIR; seven were simultaneously native physically true and source-label-concordant. Of the nine source syntax approved propositions, six were label-concordant, and six were physically true; **five** were BOTH physically true and author-type-label-concordant. The filter withheld **five** annotated original source relations. Unannotated does not automatically mean false: SceneEval gold coverage and object instance pairing are incomplete. These are source TYPE/CLASS proxies, not a validated semantic entailment, calibrated precision or general human language understanding.

This strongly falsifies "physics verified = historical source intended" and also "conservative grammatical match = universally correct source meaning."

## Experiment B: the genuine full 3D→offscreen→native save→text return, not scripted gameplay macros

BEFORE reading source gold, chose all eight previously frozen, individually physical-contact-eligible source relations, NOT the author-matching subset. These are seven distinct previously externally authored source descriptions, one containing two support relations. The same original meaning/prose, object IDs and existing GameCore physics were retained. The frozen grammar gate accepted four of these eight; the remaining four were deliberately not allowed to become source-entailed relation statements. When real physical support was evident without an accepted source role, it could still be represented as a separate explicitly PHYSICAL fact, not evidence of author-intended semantics.

For each of these eight source-driven contact configurations the study ran FOUR predeclared physical impulses using exactly the native GameCore/Rapier solver; vector directions were fixed before observing outcomes, with no gold-driven action selection. This creates **32 physical intervention episodes across eight source relations**, not 32 independent literary worlds.

Each episode:
1. Loaded the source-derived, physically validated three-dimensional scene and measured native contact/top-surface support. The original relevant source support was physically true in all eight starting configurations.
2. Used actual Rapier ray visibility to present source-approved relationships and current object facts to a possible observer. Unchanged duplicate narration was rejected.
3. Moved the observer outside physical sight, applied the real GameCore impulse, and stepped native physics. The remote observer was not permitted to see or be told an unwitnessed cause.
4. Attempted physical dematerialization only after native GameCore could actually unload the region; all eight reached that condition in each fixed-vector experiment. Advanced the same semantic world clock by seven additional seconds WHILE the region was really unloaded. Its current semantic document explicitly qualified physical bodies as unloaded, not falsely still in contact.
5. Saved the COMPLETE existing native GameCore/Rapier physics+historical source+observer/witness+semantic-document transaction, restored the exact source and stable object IDs, rematerialized the actual authoritative 3D bodies, rebuilt physical truth with a legitimate GameCore physics tick, and let the observer return only when native ray visibility allowed it.

Measured: **32/32 native source/world/observer full round trips** completed with no execution failures and unchanged original literary source/physical IDs; **30/32** real impulses changed the tracked physical support to FALSE or UNKNOWN after disturbance. The four source-syntax-approved relations produced **16 appropriate observer relationship retractions** across four vectors. There were **zero** invented eyewitness reports about offscreen impulses, zero duplicate unchanged return messages and zero source-approved claims that remained narrated TRUE after the physical contact was disproved. In one episode the observer did not regain joint visibility of both physical objects; the additional relationship statement was correctly withheld.

These are bounded factual and observer continuity results on one particular kind of physically supportable entity. They do NOT demonstrate a complete self-writing novel, general offscreen NPC life, chemical combustion, realistic source-derived interactive geometry or a general author-quality literary rewrite. The independent author annotation match in this eight-case selected subset was only **three of the four** syntax-approved source roles. One syntax-abstained source was also annotated, showing lost source recall.

One counting correction is explicitly preserved: initial informal reporting mentioned 31 physical contact changes, but complete independently checked v1/v2/v3/v4 raw outcomes actually contain **7+7+8+8 = 30**. The aggregate/evidence manifest and report use **30**, not 31.

## Experiment C: source syntax filter BEFORE native 3D materialization — strong negative

Narrator-only filtering leaves another issue: a scene can still physically construct a source relationship that the historical story did not mean. To test the more consequential architectural option, ran a second comparison on ALL the same two hundred externally authored source descriptions, applying the frozen source-only grammar gate BEFORE the existing source spatial optimizer. Only doubtful "on" constraints were removed. All other recognized source relationships, nouns, quantities, class dimensions, object IDs, original prose, native GameCore/Rapier physics and other functionality remained unchanged.

The original physical baseline was independently frozen earlier, before this study. In the 197 previously valid source scenes, there were fifty recognized parsed "on" relations: the conservative guard retained **seven** and withheld **43**. The new physical-world method again accepted **197/197** scenes, retained ALL original native body IDs and literary prose, and passed **197/197** trusted full native 3D physics/source/semantic-document save and reentry checks, with no hidden production changes. It changed the actual physical position of **28** objects across the corpus. **Six** previously parser-proposed "on" relations were now physically true and source syntax approved; zero remaining physically true parsed "on" claims lacked the source syntax gate. Actual native object-to-object contact pairs dropped from **eleven to six**. The experiment performed 64 fixed GameCore native physical impulses in the scenes with moving bodies, and 57 produced meaningful native semantic document revisions. This is a material PHYSICAL difference, not just a narrator filter.

Two source-reproducibility reporting errors were found, fixed and preserved without overwriting earlier evidence. The first consumed pre-layout v1 incorrectly summed undefined/nonexistent native action revisions into a JSON null. A separately versioned v2 corrected that, but its field labeled "verified ON sentences" was still counting ALL verified source relation kinds; the raw v2 diagnostic therefore overstates that ONE subtype count. A new EXCLUSIVE v3 run corrected the explicit ON-only predicate count and independently verifies exact type-consistent source relation enumeration. All three earlier raw files remain intact, with separate SHA-256 and source ID manifests. Other original physics results were not relabeled to hide these mistakes.

The crucial negative source-label result came from a separate post-frozen official SceneEval OORel ON scorer, requiring upright real Rapier contacting support and correctly aligned physical footprints. Among **354** author-annotated "on" requirements in the 197 materialized scenes, the original layout had **three** actual supported author-type relation matches. The source syntax gated materializer had only **two**. It gained **zero** author-supported "on" contacts and **lost one** previously correct author-supported physical relationship. Both scenes remained physically valid; neither preserved all author source meaning.

Thus **hard deleting low-confidence grammatical constraints from the physical compiler is unsafe**, even if it minimizes source-unverified physical support claims. The grammar gate improves category-level source-label concordance among asserted source facts in the narrow sample, but also drops genuine support relationships. Those rejected source propositions must remain unresolved HYPOTHESES with original source offsets and potential reference alternatives, rather than being silently discarded or made physically false.

## The architecture implied by these measured positive and negative results

The correct PRSE system needs explicit three-valued/multi-provenance source-world state, not a binary language rule:

1. **Historical literary source**: original sentences, exact text spans, actor/referent chains, quantifier/negation/conditional scope and unresolved alternatives, never silently rewritten as current physical truth.
2. **Tentative source interpretation**: source-specific entity and relationship hypothesis IDs with syntactic evidence, confidence/abstention and provenance. Uncertain hypotheses must survive offscreen time and saving even before a unique concrete asset/physical relation is chosen.
3. **Trusted 3D embodiment**: validated physical asset category, metric dimensions, collision/support/container geometry and constrained layout; refrain from pretending tiny generic boxes correctly embody a cabinet, cup, shelf or person.
4. **One authoritative GameCore/Rapier physics world**: actual events, forces, contacts, damage and offscreen processes with stable instance identities; native solver snapshot and current semantic state must preserve subsequent contact-rich dynamics.
5. **Separate current physical facts and source meaning**: a physically true support can be presented as PHYSICAL current fact; it does not prove that a misparsed original author claim intended that arrangement. Conversely, an unresolved original source claim should not be deleted forever just because the initial 3D geometry could not realize it.
6. **Observer-specific textual output**: only native physically visible objects and actually witnessed causes, with meaningful changes, deduplication and source-linked uncertainty; possible fluent model rewriting must be checked against both source and physical truth and remain a rejectable proposal.

This ordering resembles the separation of source requirements, object assets and spatial constraints evaluated by SceneEval and implemented in a different form by Holodeck/PhyScene. However **nothing here proves a working unrestricted text→3D→literary LLM**. The study used the already installed small pretrained CPU syntactic model only; no capable generative LLM comparison, original novel literary style preservation, source-blind new text dataset, calibrated human perception, independent 3D asset retrieval, shared Nitro/Thor GPU task or live PRSE deployment was conducted.

The strongest next experiment is instance/referent-aware and hypothesis-preserving on a genuinely new source dataset: propose multiple compatible source interpretations, obtain validated 3D assets/affordances, optimize only supportable source constraints, physically check native contacts and observer event consequences, and have an independent source/physics entailment checker reject unsupported literal narratives without losing undecided alternatives. Score source meaning, physical scene fidelity and current writing quality separately. No source parser trained on already seen SceneEval gold should be passed off as a prospective validation.
