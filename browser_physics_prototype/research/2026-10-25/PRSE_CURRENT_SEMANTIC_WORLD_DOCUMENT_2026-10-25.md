## New question and method

Can PRSE maintain a regenerable CURRENT textual world document rather than only an archived source paragraph and an append-only factual update stream, without ever misrepresenting unobserved physical state or source-proposed relations as verified?

The new PRSECurrentSemanticDocument is a research-only layer on top of the SAME PRSESourceRevision, GameCore/Rapier physics, existing physically grounded source relations and event-time ray-based observer. The historical original literary text remains byte-preserved and source-hashed. The new current document represents stable physical entity IDs and three distinct cases: bodies genuinely present in authoritative 3D, identities whose area is unloaded and therefore have only qualified semantic records, and destroyed historical objects with separate source-linked physical remains when available.

For each interpreted source relationship the document retains physical TRUE/FALSE/UNKNOWN and a reason. It may print only physically verified TRUE relationships; physically contradicted or unresolved relationships remain diagnostic metadata, not current asserted prose. Real physically confirmed support not recovered by the weak source interpreter can also appear in the current document, but with an explicit marker stating it is a PHYSICAL observation, NOT a claim about what the original text meant. Statements use stable IDs, current world time and evidence provenance. The internal world document is an omniscient state projection; the PLAYER readout still uses the independent physically ray-tested observer and witnessed-event journal, so the mere existence of a hidden event in world history is not permission to disclose it to a character.

Meaningful semantic changes, not each numeric frame or elapsed second, increment a versioned revision history. A complete trusted transaction combines the real native Rapier whole-world snapshot, ordinary GameCore source/semantic state, observer histories and this current document journal; restore reconstructs the current text from the actual saved physical world and checks the stored claim signature. This is not a production multi-region save format or a replacement for a prose-writing model.

## Main two-by-two-hundred actual 3D evaluation

Used the SAME frozen first one hundred human SceneEval descriptions and the SAME systematically selected one hundred assisted source IDs for EACH of the prior frozen deterministic and combined syntax interpreters. All valid scenes were materialized and stepped through native GameCore/Rapier, a regenerable current document constructed, an unchanged second read checked, a real impulse applied to the first available dynamic object, semantic truth revisions recorded, and the full native physics/source/observer/document transaction saved and restored. The restored current text and source-relation truth were compared with an uninterrupted physical world after another actual physics step. Official SceneEval annotation labels were NOT read by the document generator.

The first deterministic run retained a concrete new failure: seven otherwise valid scenes were rejected by the current document restore code because it required the last meaningful semantic revision to have the SAME timestamp as the latest GameCore physics snapshot. Time can advance without a meaningful textual/world fact change. The original failed v1 source IDs and raw evidence remain untouched. The corrected invariant accepts a last recorded semantic revision EARLIER than the current world clock while still rejecting reversed history, mixed source identities and different current physical claims.

## Offscreen semantic world and causal return

A separate illustrative test used the original owner's paper/wooden-desk/offscreen-fire research scenario, explicitly marked as authored rather than an independent human or SceneEval participant. Initially both note and desk existed as real native 3D bodies. After legitimate dematerialization, the current textual world remained nonempty: it retained qualified records of their persistent semantic identities while explicitly withholding fresh physical contact and position claims for bodies not currently simulated. An authored offscreen ignition/process rule advanced the world clock for twelve seconds, recorded the original note's destroyed historical identity and produced a distinct ash remnant with source lineage; it did NOT simulate chemistry.

The complete inactive native world/source/observer/current-document transaction survived saving. Rematerialization returned a real ash rigid-body collider, and the current world document described the existing ash and historical destruction without replaying the original room description as if unchanged. The independent visiting character saw the ash but received zero invented eyewitness ignition events. A second save/read produced no duplicate observer text and both world clocks agreed.

A separate actual human-authored SceneEval lamp/nightstand case verified that physical support is included as a current relationship only while confirmed. A real GameCore impulse removed support; the current document dropped the old assertion and preserved its semantic change history while keeping the original source paragraph archival. Regenerating the text after native saving produced the same current claims. The old fact-timestamp bug is fixed for this no-new-semantic-change passage of physical time. Corrupted claim signatures and future-dated revisions were rejected, even when internal hashes were recomputed. This is owner-trusted save integrity, not cryptographic authentication of hostile alternative worlds.

## What is answered and what remains

The work establishes an independently verified CURRENT source-linked, physically constrained, regenerable semantic-state document, with meaningful revision history and explicit distinction between live physics, historical destruction and unloaded semantic identities. It demonstrates that the world can still be described in qualified textual form while 3D bodies are unloaded, without silently inventing unseen contact or motion. It also retains the full previously verified physics/observer save boundary and source provenance.

However, this is a **factual projection of structured authoritative entities**, not the complete original ambition of the CURRENT WORLD ITSELF being coherent, evolving ordinary literary text. The source-to-physical interpreter remains very weak. No model performed source-aware stylistic literary rewriting; no human reader evaluated prose quality; no general character dialogue, conditional/negation/coreference reasoning, unsupported physical materials, cross-region active NPC life or arbitrary multi-region source text generation was demonstrated. Existing source excerpt studies showed literal phrase substitution is unsafe for most descriptions. Even correct native 3D facts will need an independently constrained language-model rewrite stage whose every asserted claim is checked against the authoritative scene, source provenance and character knowledge.

A scientifically defensible next experiment is to fix original literary paragraphs plus before/after verified 3D state, actor identities, true/false/unknown claims and observer-specific events, and compare deterministic current factual paragraphs against one capable language model and, optionally, a separate entailment verifier. Evaluate unsupported factual claims, omission of important changes, reference stability, stylistic quality, causal privacy, save/re-entry fidelity and response latency on genuinely unseen source worlds. Shared production inference resources were occupied during this task, so that comparison was not fabricated.
