## The original questions, each answered with the strongest verified outcome

**One: does model-extracted original human prose reliably create correct object types and correct count?**

**No.** The earliest SceneEval author-count baseline materialized **565 of 1,237** originally annotated object-count requirements. The original 200-scene sample had 197 genuinely valid scenes across compared methods. The independently interpreted LEGO-Bench original human corpus contained **130 scenes**, most larger than the real in-game text length limit. An offline older same-source builder created **575** real nonwall object bodies across all 130 scenes; the expanded source-only method created **678** by adding 103 provisional bodies. Strict overlap with independently constructed reference object **ID categories** improved from **251 to 294 out of 6,844 listed reference object rows**, without proving author-room identity, geometry or full recall. The external reference itself has naming/group/instance inconsistencies and is not a complete strict literal author gold for every native collider.

The real **two tested game WebSocket versions** created exactly **zero of 130** externally human-authored complete scene requests: **128** rejected for text length and two returned unsupported help. Another 1,250 independently author-annotated clauses elicited **19** length rejections, **1,229** help/fallback replies and **two** spurious forest-game action dispatches. This is directly measured *end-to-end backend output*, not a model text-completion proxy. No production user scene importer was deployed.

**Two: do source-relative spatial constraints, stable unique referents, geometry, metric dimensions and physical supports become the author's actual 3D world?**

**Not reliably.** Original SceneEval author-intended vertical ON support confirmed through real Rapier native contacts was **3/354** with control and **11/354** with pretrained source-only proposals, but **all eight additional support matches came from partly machine-assisted scenes**; the original first 100 purely human-authored cases saw no improvement. The assisted-source paired estimated gain of about +2.21 percentage points (95% cluster bootstrap +0.77 to +4.11) is conditional on previously examined source and must not be described as independent genuine human-language generalization.

In a separate original-human LEGO-Bench same-body 130-scene experiment, the existing 678 collider IDs/types/sizes were held identical across source-conditioned physics arms; native contact pairs increased from **5 to 11**, without prior contact loss. Independent postfrozen phrase adjudication showed **only ten genuine geometrically vertical top supports** among the eleven; **nine corresponded to selected author-positive source clauses but were chosen posthoc**, one actual lamp–bed contact **contradicted** the author's “lamps on either side of the bed” description, and one contact was non-top/composite. None establishes broad author-source true-positive or false-positive population rates. The formerly attempted random physically feasible *alternative-parent* placebo was **denied** and NEVER executed. No causal-specificity claim against that missing control exists.

LEGO-Bench has **95 of 130** multi-room original scenes. Previously implemented single-room generation does not source-ground multiroom instances. Some room-specific independently human-annotated negatives were apparently satisfied only because *positive-required* objects were omitted entirely. Source author scene twenty requires a **bed in kitchen** and **refrigerator in bedroom**, yet forbids bed in bedroom and refrigerator in kitchen. The earlier actual native method included neither required object. The reference JSON additionally contained **89 out of 2,938** `child|parent (room)` links whose exact standalone parent ID was missing in the same room; these are ambiguous reference links, NOT proof a live physical collider floated, nor author-correct proof of a forbidden object.

The later restricted research prototype took **three previously studied human scenes**, retained eight source-qualified spatial regions (physically implemented as forty-eight fixed Rapier floor tiles) and generated seventeen actual source-qualified dynamic generic BOX bodies. **Seventeen** accepted subset object instances and **four** exact forbidden room-kind combinations passed independent author-positive/negative checks through real native save and restore. Nevertheless **none** of the three original full source scenes passed: two computers were really supported by floor rather than the author's desk; source-required adjacent rooms had an **eight-metre actual floor gap**; unmodeled appearance, walls, doors, materials, object mesh shape and source constraints remained unknown. These are **posthoc bounded functional demonstrations, not heldout evidence of general literary generation**.

**Three: does generic learned/source noun interpretation transfer to genuinely different independent human language?**

**Only modestly, and fails the preregistered standard.** A new independent **Nr3D/ScanEnts3D** source has thirty-seven thousand eight hundred forty-two human freeform 3D reference utterances over 641 distinct scans. Original source and independently 3D-labeled target kinds/instance IDs were separated and source-only predictions FROZEN before the scorer read gold. The test used **480 scene-independent utterances**. Strict category accuracy improved from **231/480 (48.125%)** old PRSE lexical to **309/480 (64.375%)** source-only pretrained English nominal extraction, **+16.25 percentage points**, paired scene-level bootstrap **+11.67 to +20.83 points**, with 104 wins versus 26 losses (exact paired p approximately 3 × 10⁻¹²). The preregistered **75% absolute accuracy** threshold FAILED. **Zero independently correct unique ScanNet object instance IDs** were generated, because the parser did not supply per-instance IDs. Of 71 naturally occurring narrow non-top idiom/negation controls, zero were promoted to top-support proposals (Wilson 95% upper bound about **5.13%**, *only for that selected narrow idiom*, not population false-positive rate).

Thirty-one source-only Nr3D physical trials executed 62 paired real GameCore/Rapier worlds with identical provisional two-body inventories: **15** source-nominated contacts physically appeared; sixteen natural non-top negative cases generated zero new contacts; all 62 actual native world saves/restores passed. However independent 3D phrase annotation identified the right *child* target category in **11 of 15** and separately annotated supporting-object category in **4 of 15**; the two real box surfaces and dimensions were **provisional**, not checked against original ScanNet scan meshes or real supports. These fifteen are mechanics feasibility, **not fifteen correct human-world supports**. A later three-phrase compound-noun correction improved the already exposed 480-example sample from 309 to 336 category hits (**70%**), but was **posthoc designed from this same gold**; it is NOT another heldout success and does not reverse the original acceptance FAIL.

**Four: does real 3D physics actually work, and do physically caused events persist offscreen?**

**Yes in bounded genuine native experiments, not as general source fidelity.** GameCore/Rapier is genuinely used: 3D colliders, forces/impulses, contacts, event logs, and native world snapshots. Seven independently authored source **reconstruction stress cases** performed actual offscreen dematerialization and restored original source and every object ID; six received genuine dynamic impulses and moved. A real browser-button-to-private-worker candle/paper study observed Rapier contact followed by actual semantic scorch/ash effects and physical object re-materialization on return, and rendered that result in the real browser. **This was a separate research worker**, NOT the player's actual arbitrary original literary room, and did not alter that player world. No general heat/combustion physics, fracture, arbitrary source causality or complete observer truth was thereby proven.

**Five: does native saved identity mean the future reloaded physics is exactly the same?**

**NO, new independent physical counterexample.** In three previously human source-derived real native 3D scenes, research independently reconstructed **all 65** actual native rigid bodies, matching the earlier 38-tick positions within about two micrometres and exact contact-pair IDs. Binary Rapier snapshot/restoration was **initially exact** across **twelve** tested continuation scenarios (sources, IDs, pose, speed, quaternions, time and contact IDs); JSON-only structured restoration had matching initial positions but not the original contact-pair set.

Actual *future outcomes* were measured by branching uninterrupted GameCore, binary-restored GameCore and JSON-restored GameCore, applying **exactly the same native GameCore impulse to the same real source-linked object**, and ticking real Rapier for three seconds. Three no-action negative-control runs agreed exactly after binary restore. But **two of three high-impulse cases** had different final native restored positions, maximum **0.2177102 metres**. Six additional lower/medium/strong physical-action cases yielded **four of six** binary-restored trajectories diverging by over **one centimetre** (maximum again 0.2177102 m); one of six was within half-millimetre. Structured JSON restore diverged by up to **0.6587755 m**. Contact pair IDs, source, object IDs, time and tick counts still matched, so these invariants are NOT sufficient to claim deterministic physical future. The precise engine-level cause was not proven. Strong physical motion sometimes placed an object **outside its original source room**; a physically checked current-state report has to mark its current room **unverified** rather than repeating a historical source label.

**Not verified.** Bounded deterministic all-world physical statements can be read back from actual Rapier bodies; a research ray-based observer filters some witnessed physical events; older bounded offscreen semantic cases preserve historical source and IDs. But no independently human-adjudicated **complete original literary scene → source-correct scaled/materialized 3D → emergent forces/events → observer-limited fluent and truthful present literary world → hidden offscreen continuation → faithful reentry** test exists. No measured global observer event TP/FP/FN, no source-truth literary hallucination rate, and no independently calibrated general room/mesh fidelity. The attempted large broad observer/offscreen experiment was **blocked**, its unexecuted version archived privately, and was NOT repeated here.
