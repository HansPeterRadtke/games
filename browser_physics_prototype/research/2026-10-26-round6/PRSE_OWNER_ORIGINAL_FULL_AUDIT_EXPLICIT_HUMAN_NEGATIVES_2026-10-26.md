## Original owner goal, source authority and decision

The original four owner voice recordings, dated 13 August and 9 October 2026, describe a **persistent literary/semantic world as the game’s central representation**, which can be instantiated on demand as **one authoritative, true three-dimensional physical GameCore/Rapier world**. Object kinds, metric sizes, asset/collision geometry, number, persistent identities, room-specific placement, supports, real contact, forces, causal events, perception and current world history must be correct. The simulation changes have to be written back into **coherent, observer-limited literary state**, including hidden offscreen time, save/reentry and rematerialization without resetting identities or hallucinating witnessed causes. The core is independent of rendering, text, 2D or full-3D output; player macros and learning habits are explicitly secondary.

**The general goal is PARTIAL / NOT VERIFIED.** The engine and bounded physics/causal demonstrations work. Unrestricted human literary source → correctly identified, scaled, spatially arranged real physical 3D → independent observer-safe literary prose does not yet work or validate. The existing playable game does not even import complete external literary scenes. Do not deploy an “automatic PRSE literary world generator” into a player’s authoritative session based on these positive subtests.

Source policy: actual original author statements and human annotated constraints establish **literary intent**, but do not prove that the experimental GameCore created that world. Native Rapier collision manifolds establish **actual simulated physics**, but do not prove that the arrangement was authored. Independent LEGO-Bench reference JSON is a manually constructed **example 3D scene**, useful for reference identity checks but potentially internally inconsistent. Released reference child–parent ID metadata cannot override explicit original author negations. The existing bounded semantic current-world document is all-knowing and must never be mislabeled a player-observer narrative. An independently observer-qualified report may state only appropriately witnessed physical facts/events; historical source stays historical.

## Original user questions, individually audited

**First: can general literary text be interpreted and converted into real geometry?** Only partially offline, and not in the actual user game. First source-only studies on the 200 tested SceneEval descriptions found baseline object-count fidelity 565/1237 independent author count clauses; fully human original scenes saw no improvement from the pretrained support parser. A second independent human-written LEGO-Bench corpus has 130 complete descriptions; existing browser GameCore rejected 128 because of its 120-character input limit and gave unsupported help for the other two. Both evaluated code versions created **zero** intended author scenes. The independent source-only research parser recognized additional nouns, but those are **provisional guesses** with mostly generic boxes. It is not the deployed source interpreter.

**Second: can the active world instantiate correct individual source objects and rooms, category/count, scale/pose/mesh?** Actual 3D bodies exist. In the human source comparison, the older parsed setup had 575 physical bodies across 130 scenes and the expanded source-only one 678. Strict exact-category reference-ID matching found at most 251 and 294 possible object-kind instances respectively. These are **category upper bounds**, not verified author-intended instances or physical accuracy. Of 130 independently constructed human examples, **95 require multiple rooms**; the current research source-to-scene generator uses a generic single-room plan without reliable source room-qualified instance IDs. The dimensions/primitive meshes were uncalibrated estimates. Individual geometry, contact surface plausibility and real object identity remain unproved.

**Third: do source statements such as “A rests on B” become independently accurate physical support/contact/forces?** Real GameCore/Rapier supports and impulses are proven for narrow examples. On the extended human corpus, the frozen identical-body comparison had **five** true nonwall contact pairs in control and **eleven** in the source-conditioned world; six new contacts, none lost. But after real quaternion/top-surface/manifold validation, only **ten** contacts were geometrically vertical supports. Of those, nine correspond to **posthoc-selected author-positive source clauses**, one is a real *lamp–bed* contact but the author's source says nightstands with lamps are **beside** the bed. Another actual contact is nonvertical or composite. These counts cannot establish general heldout precision/recall, because the author subset was selected after seeing successes and there is no exhaustive independent pairwise negative annotation. A previously denied feasible-alternative/random-support native placebo remains denied, unexecuted and not silently substituted.

**Fourth: can real physics/forces produce true events, causal effects and coherent offscreen progression?** Yes in bounded experiments, not general literary worlds. Round three took seven human-source reconstruction cases; six dynamic objects received real GameCore impulses and moved, semantic revisions were recorded, all seven underwent real offscreen unload and preserved original text/IDs on restore. A separate current game UI worker running an isolated candle-paper-causality experiment demonstrated real Rapier contact, resulting note ashes and bench scorch on offscreen advance and physical note rematerialization. That demonstration was **in a separate worker world**, not automatically in the player’s literary scene. Fire, damage, fracture and complex semantics beyond tested domain are not proven general.

**Fifth: does real simulation return to truthful observer-limited prose, retaining visible/unseen event distinction?** Only conditionally under bounded deterministic text/observer tests. The research current-world document distinguishes historical source and native physical current clauses and exposes observed events through a separate ray-test observer. It is not yet a full literary rewriter. Full independently human-adjudicated current observer prose after arbitrary causal source scenes is unavailable; unknown or unobserved causes cannot be invented. The owner’s desired general native-observer full-corpus experiment was **not executed in this round because its execution/patch was blocked**. The unexecuted draft has been archived privately as a separate unvalidated source artifact. No retried or disguised operation followed the denial. No new observer recall or false-positive result is claimed.

**Sixth: does the persistent world save, unload, evolve out of view, reenter and reconcile the same identities?** Existing seven original-human hard native cases preserved original text and object IDs across real offscreen save/restore. The generic forest playable WebSocket session reliably persisted movement and reload. Those are genuine but separate bounded checks, not full independent literary-world generalization or exact source-qualified instance rematerialization in 130 multi-room human scenes.

**Seventh: what is the deployable cost/latency and choice?** Current game responds rapidly but with help/rejection instead of source worlds. In full original human scene + 1,250 independently annotated clause WS testing, both committed and current-canonical-source private GameCore versions gave exactly the same replies: 128 of 130 complete literary scenes over input limit, the other two unsupported; 19 annotated clauses over limit, 1,229 unsupported help, and two incorrect unrelated game-action dispatches. Source-specific author scenes created: **zero**. Median WS response was roughly seven milliseconds; this measures fast failure, not real scene generation. Earlier CPU parser proposal generation used about seventeen seconds across 130 scenes and paired source-only native physics used about forty-six seconds for 260 total world-arm executions. LLM and GPU costs and genuine arbitrary literary end-to-end latency remain unmeasured. **Decision: maintain native GameCore but fail closed on unsupported literary import; add a provenance-aware source-qualified importer only after independent tests.**

## NEW independent original-human room-negation test: why false negatives can falsely look like negative success

This is the substantive separate permitted experiment of round six. It reads only original **independently human-authored and annotated** source clauses, official public reference snapshot IDs and **already frozen real native GameCore/Rapier body inventories** from both baseline/expanded methods. It performs no placement or physics replay. The older and expanded original physics files are verified by SHA-256, and private content remains owner-only.

We identified **four** explicit, narrowly scoped human **Object Placement/Floor Layout** room-absence statements from **three** scenes, using the exact preselected grammar **“There is no [refrigerator/bed/door] in the [kitchen/bedroom/cell].”** Counts are **not an exhaustive negative-label sample**. Every frozen native model arm lacks the named forbidden kind *globally*, so none directly exhibits a forbidden-kind body that could violate those negative statements in the forbidden room. However, the native bodies have no independently verified per-room provenance, so “nothing present anywhere” does not prove correct room semantics.

The decisive hard case is independently human-written scene twenty. Its annotated source separately says:

> There are a treadmill and a bed in the kitchen.
>
> There is no refrigerator in the kitchen.
>
> In the bedroom, there is a refrigerator and a kitchen island.
>
> There is no bed in the bedroom.

Both older frozen and expanded frozen actual native worlds contain **neither a bed nor a refrigerator/fridge anywhere**, although the author requires one of each in *different rooms*. The source negative is superficially satisfied by a **direct failure of two positive source requirements**. This proves two exact previously missed global physical source-positive kind omissions in both arms, not two physical false-positive collisions. The independent 3D reference does have the explicit bed instance in the kitchen and the refrigerator in the bedroom, supporting those two original human positives.

The external reference metadata creates an additional contradiction with the very same human negation. It lists **five** room-scoped `pillow/bedside-lamp|bed` child–parent ID strings under the forbidden **bedroom bed**, and **two** `cereal|refrigerator` links under the forbidden **kitchen refrigerator**. Crucially, the referenced forbidden parent bodies do **not** exist as corresponding standalone physical reference IDs in those rooms. These are **seven inconsistent source-versus-reference-link records in two of four independently authored negative room-object clauses**, not evidence that actual reference colliders violate the author instruction.

Across all 130 official example-world reference files there are exactly **2,938** `child|parent (room)` reference strings. **2,849** specify an exact standalone parent `id` that exists in the same room; **89** do **not**. Strict parent-ID misses may be group/nested/alias metadata or absent reference parents; they are **not an independently confirmed collision false-positive rate**, nor a proof that all 89 objects float physically. They are a demonstrable obstacle to treating reference `id` strings as unquestioned per-instance physics authority. Refusal to overclaim that missing parent is important for any benchmark parser evaluation.

## Operational next step and exact remaining evidence

The next *permitted* high-value implementation work is to create an explicit source-derived spatial fact layer before any physical world approval: `entityId`, `roomId`, positive and negative room-scoped kinds and quantities, individual referents/aliases, metric collider source, support/attachment direction and source clause provenance. **Negative and positive constraints must coexist**, so deleting all beds cannot pass “no bed in the bedroom” while erasing the required kitchen bed. Preserve original literary source as history and true GameCore events as current authority. Then test independently authored final observer prose and real offscreen reentry on a genuinely heldout human source corpus, without reattempting denied effects.
