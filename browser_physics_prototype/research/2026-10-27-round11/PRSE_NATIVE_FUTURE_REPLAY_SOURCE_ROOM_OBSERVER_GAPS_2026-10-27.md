## NEW actual independent native post-save continuation experiment

This round was designed to test **future physical outcomes**, not merely inspect saved files. The new isolated source-derived world builder read frozen author `instruction` source-only room manifests from the prior round and independently materialized exact original source-qualified rigid body IDs, kinds, provisional collider sizes, masses and the same eight spatial floor regions. It opened no author gold labels or released reference meshes. All three real generated worlds passed source and native 38-tick pose/contact identity checks against the separately frozen prior GameCore research output, which safeguards against an accidental toy fresh start.

After those verified physics baseline states, it created three physics future branches: (A) uninterrupted actual GameCore/Rapier world; (B) same real world restored from its trusted binary Rapier snapshot and associated structured state; (C) project’s older structured JSON-only state restore. It applied the **same real GameCore external impulse** to the **same source-derived dynamic body ID**, or **no action** as a negative control, then performed **180 genuine subsequent GameCore/Rapier physics ticks** on each of the three branches. It independently compared every object ID, category, size, source room, current native rigid body translation, native linear velocity, quaternion, contact-pair IDs, world clock and physics step count across the branches. No random alternative parent was chosen, no fake 2D slots or model-mediated latent positions were used.

**First frozen v1 controlled study** across the three previously human-written source worlds, each with a no-action and a high-impulse future scenario, produced:

- All **six of six** trusted native restores matched the initial actual-world state, source/history, clock, ID, native contact-pair IDs, poses and velocities immediately after restoration. Structured-only JSON restoration did **not** reproduce the existing initial contact-pair IDs in any of six cases, despite initial matching poses.
- **Three of three no-action negative controls** preserved subsequent native poses identically.
- **One of three** high-impulse action cases preserved the future native trajectory to the exact strict geometric tolerance; **two of three failed** exact subsequent 3D pose replay with binary save, with max errors of about 22 cm and 6 cm. Full source and clocks remained identical and contact-pair IDs matched, meaning those coarse checks would have been false passes.
- Older JSON replay showed up to about **66 cm** pose difference after the same impulse.
- Under large physical motion, original source `roomId` descriptions became stale for the kitchen bed and, separately, a bedroom refrigerator. The historically source-qualified room IDs still existed, but actual native positions showed each body had left its original physical room region.

The independent **v2 impulse-strength diagnostic** targeted only the two already observed failure scenes, with three distinct source-blind amplitudes (**low, medium, high**) for the same original source-determined dynamic body per scene. This is a NEW physically measured amplitude study, not a repeat of the earlier denied feasible-parent assignment.

It used 30-, 120- and 180-tick actual native checkpoints. **Six of six physically moving cases** completed successfully, with actual displacement well above half a metre. Four native restored trajectories had a **final position discrepancy greater than one centimetre**, one was within a half millimetre, and another differed by roughly one-and-a-half millimetres. The largest new native discrepancy was again 21.77 centimetres, and the largest structured-JSON discrepancy 65.88 centimetres. All saved sources, body IDs, physics clocks and contact-pair IDs agreed. In several cases measurable differences were present by the first 30 ticks.

These samples were **previously seen source scenes** and amplitude values were diagnostic choices, not population-random heldout labels. They do NOT justify a numeric general failure-rate confidence interval. The media/mesh/true source geometry has not been independently calibrated. Cost: v1 measured **17.997 s** real Nitro CPU-bound wall for six three-branch native scenarios (median about **2.14 s per scenario**); v2 **17.466 s** for six further three-branch scenarios (median about **2.50 s**), plus independent read-only verification. These timings include rebuilding and multiple physics paths and are **not** per-player response latencies, GPU use, or LLM inference cost. Nitro is under substantial concurrent system load and comparisons are not controlled against that contention.

## New explicit positive/negative controls and failure guards

- Positive-control original human scene source object: a real dynamic source-linked native body actually moves under a true applied GameCore force.
- Negative-control physical scenario: no future action gives exactly identical trusted native binary future physics in three independent original human source worlds.
- Save-origin correctness: every new builder world must reproduce exact prior native source body inventory and previously frozen real initial contact-pair IDs *before* it may enter the comparison.
- State identity guard: two branches cannot pass by retaining the same approximate positions while losing source body IDs, kinds, dimensions, source, physics world time, or contact-pair IDs; all are checked separately.
- Current-location narrative guard: an object's archived room name cannot be reused as current physical location unless the body's **actual native position** is inside that room's **actual physical** assigned region. When it leaves, the bounded current description must mark the location unverified.
- User's original hard source-negative and support checks are still required: no bed in the bedroom if the author requires bed in kitchen; no refrigerator in the kitchen if the author requires it in bedroom; computer *on the desk* requires native desk-computer contact, not merely a desk and computers with the same room metadata.
- Full-source acceptance remains **zero** until the unmodeled geometry, contact, topology, observer and literary requirements pass. No claim of observer-safe model prose was added.
