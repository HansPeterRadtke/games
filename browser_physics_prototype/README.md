## Runtime correction (October 10, 2026)

The original public URL now serves only a **thin, remote browser viewer** of the Nitro-hosted, authoritative PRSE game simulation. The actual GameCore, Rapier 3D physics, semantic world, commands, saving, event logs and optional Jetson-LLM interpretation run in the separate headless `../prse_runtime/` service. Browser code no longer advances physics on the main public page. `viewer.html` / `viewer.js` are the presentation/controls adapter; the older standalone browser experiment is retained as `index.html` / `game.js` only for historic tests and saved games. See `../prse_runtime/README.md` and its doability study. This change trades continuous offline play for reliable server state/logging and LLM access, with automatic reconnection after mobile-link interruptions.


Live URL: `https://nitro.jonnyontherun.org/llm_game/` (the same historical Nitro game URL). Local source: `browser_physics_prototype/`; Apache continues to serve `/llm_game/` from `LLM_Game/web/`, whose entry page has an explicit same-origin base path to this prototype. Do not rewrite the Apache proxy or other live game/server services.

The current demo scenario is a short playable **exploration and repair** experiment, not a ragdoll game. Go left to find planks by the old beech, carry two of them, cross the fence, travel right to repair the missing footbridge deck, jump the obstructing crate if needed, and cross the stream. Experiment at the old mechanism by measuring a recurring hidden signal and trying to activate the lifting fence at a suitable time. The field journal preserves measurements. More geographic content is pre-generated ahead from validated semantic proposals, including reviewed local-LLM story branches that depend on physical bridge and mechanism state.

Manual controls: A/D or arrows (move), Space (jump), E (interact/pick up/inspect/repair/talk), F (experiment at mechanism), G (automated fence crossing), Escape (cancel), Enter (focus command input). Touchscreen buttons expose the main actions. The text input supports descriptions, interaction, measuring, timing, interruptible waiting, and semantic fence crossing, with an additional strict bounded natural-language action matcher for ordinary phrases such as “put out the flame” or “read the handwritten note”. Beyond the stream is an LLM-translated shelter with a supported oak bench, candle, jug and handwritten note. Reading, lighting, burning and extinguishing objects produce lasting semantic and physical consequences. An off-screen fire evolves through causal stages; returning reveals visible soot and ash. A traveler learns about the event only if they witness it or the informed player tells them. Saving and loading preserve physical state, coarse semantic state, journal, carried resources, bridge, and fence. Saved version 5 is used for the larger game; the implementation accepts older prototype save versions for compatibility.

Core architecture: `physics-core.js` owns authoritative game state, Rapier stepping and event ordering. `world-seed.js` stores the starting authored text/object facts. `semantic-world.js` owns persistent PRSE facts and coarsely simulated off-screen entities; `world-bridge.js` owns conversions into real Rapier bodies and back. `world-generator.js` owns bounded, state-dependent ahead-of-player proposals and validation; `scene-translation.js` corrects the support relations of the constrained local-LLM scene; `world-consequences.js` preserves delayed off-screen narrative consequences; `narrative-view.js` projects current facts to text without revealing unseen events; `semantic-command.js` parses a small set of everyday action/object phrases, rejects unknown or ambiguous requests, and routes valid intents through the same distance-checked typed core; `llm-proposal-sample.js` records one validated local-LLM output for offline deployment, not live inference. `gameplay-rules.js`, `hidden-mechanism.js`, and `character-model.js` implement independent game-domain decisions. `side-view-renderer.js` only draws state and receives no authority to change the simulation. `text-adapter.js` exposes a separate headless text representation. `game.js` is only the browser/keyboard/touch adapter. `active-ragdoll.js` remains a separate optional doability lab; its controls are collapsed away from ordinary gameplay.

The renderer uses CC0 Kenney images from New Platformer Pack, with the existing local asset collection stored on the Raspberry Pi. The physics backend is pinned to the project's vendored Rapier 0.17.3; no CDN is needed while playing. See `PHYSICS_DOABILITY_2026-10-10.md` for measured feasibility, limitations, and unsolved requirements.

Tests: `./tests/run-game-tests.sh` runs deterministic physics, game, hidden-system, world, save/restore, renderer contract and performance studies without browsers. `tests/browser-smoke.py` runs the public browser E2E using an existing Nitro CDP host, creates its own temporary isolated browser context, and never closes unrelated tabs. `MOBILE=1` selects a 320 CSS-pixel emulated viewport; `SCENE=1` checks the physically generated shelter, in-browser object interactions and fire stages. Use `GAME_URL='https://nitro.jonnyontherun.org/llm_game/'` to verify public delivery. This test utility uses the Nitro virtual environment Python packages and local Chromium CDP.
