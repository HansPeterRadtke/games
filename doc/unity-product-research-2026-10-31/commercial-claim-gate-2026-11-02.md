# HPR Unity: commercial differentiation gate, November 2, 2026

**Decision: NO-GO for public submission.** This evidence is a narrowly
scoped current Unity marketplace comparison, not real buyer sales,
purchase intent, competitor software testing or a valuation.

## Actual competition that already markets the central HPR buyer promise

Ability & Combat Toolkit (ABC), original listing:
https://assetstore.unity.com/packages/tools/game-toolkits/ability-combat-toolkit-155168

The live November 2 listing advertises 83 rating entries and 1,225
favourites, a temporary USD 39.12 sale price against USD 78.25 normal
listing, support for the **buyer's existing movement and camera
controller**, ability setup with **two components**, a visual Editor,
ScriptableObject asset definitions and integrations with Game Creator
and Emerald AI. Vendor documentation separately claims support for
both old and new Unity input backends:
https://dicelockstudio.gitbook.io/abc-toolkit/abc-components/general-settings/key-and-combo

These are **seller descriptions**, not independently imported or
tested code. Nevertheless, they directly undermine any HPR claim to
be the first or unique asset capable of adding abilities while leaving
a customer's existing controller in place.

Game Creator 2, primary original marketplace listing:
https://assetstore.unity.com/packages/tools/game-toolkits/game-creator-2-203069

The original listing reports USD 79.99, 418 overview ratings and
2,489 favourites, while its separate reviews page currently exposes
352 individual reviews:
https://assetstore.unity.com/packages/tools/game-toolkits/game-creator-2-203069/reviews

Many reviews praise the no-code workflow, saved development time,
examples and breadth. One specific review (Virillus, approximately
eight months before this observation) calls the documentation
inadequate despite excellent functionality, giving an anecdotal
pain point: **discoverability and accurate documentation of existing
game integration**, not absence of another combat/ability framework.
One review cannot establish prevalence or willingness to pay.

Game Creator's own documentation explicitly describes ways to extend
its character controllers with custom source:
https://docs.gamecreator.io/gamecreator/characters/component/

ABC offers a separate paid Game Creator 2 integration, demonstrating
supply for cross-tool composition but not reliable purchase volume:
https://marketplace.unity.com/packages/tools/game-toolkits/abc-integration-game-creator-2-218546

## Original Unity rejection reason and current requirements

The previous nine small HPR modules were declined on October 8, 2026
for an unusually high volume of similar AI-assisted offerings
diluting unique value, rather than an explicit programming ban.
The owner cannot solve that rejection by republishing the original
nine separately, opening a second publisher account, or merely
combining the exact same low-depth modules into a new storefront SKU.

The current first-party submission guidelines were last updated
October 23, 2026:
https://marketplace.unity.com/publishing/submission-guidelines

Sections 1.6.a and 1.6.d require transparent functional AI assistance
and significant added value; 2.1.f/h reject largely identical separate
submissions or unmodified previously rejected work. For a Unity 6.5+
submission, 1.3.c requires URP or HDRP compatibility. Section 2.5.h
requires domain-reload-disabled Play-mode safety from Unity 6.6.

## Actual current HPR and objective falsification

Verified HPR work so far:
- One specific existing customer controller/scene preserved with
  independent healing ability attachment, Undo/Redo and original
  customer file hashes in real Unity 6.6 tests on the previous archive.
- Seven reviewed source/doc improvements in a SHA-pinned private new
  archive with 161 stable GUIDs, ten clean assembly definitions and
  deterministic byte-for-byte package assembly.
- The new private archive has NOT passed actual Unity Editor import,
  URP/new-only input, custom Stats Play mode or buyer-file preservation
  tests. Existing staged customer projects each contain only part
  of the seven changes and cannot certify the new archive.

**Falsifiable product hypothesis:** a professional Unity developer
already maintaining a complex game can add a small healing ability,
configure its owned resource source, save and reopen the game, upgrade
the toolkit and remove the feature with materially fewer steps and
unexpected buyer changes than existing paid competitor solutions.

This is a hypothesis. For a real priced product, record at least one
independent, experienced Unity developer completing the same task
in a genuinely existing project against ABC or another installed
competitor. Record actual task duration, changed customer source
files, controller/input incompatibilities, scene and GUID mutations,
number of Editor errors, manual fixes, cleanup/Undo and support needs.
No competitor was purchased or installed for this study; **all
HPR-versus-competitor numbers are currently NOT MEASURED**.

If an existing paid toolkit completes the same task as quickly and
without significant customer disruption, the product has no
demonstrated commercial reason to exist as a separate HPR SKU.
Do not set a selling price or publish from synthetic QA counts.

**Current decision: commercial NO-GO.** No marketplace submission,
account change, purchase, advertising action, user testimony or
sales claim was made during this evidence review.
