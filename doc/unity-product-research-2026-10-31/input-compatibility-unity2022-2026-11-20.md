# Input Compatibility Auditor — Unity 2022 installation failure and patch, November 20–21, 2026

## Defect and exact reproduction

The older internal release `release-v7/hpr-input-readiness-candidate.unitypackage` had native Unity 6000.6.8f1 acceptance but **did not compile in Unity 2022.3.22f1**. Import into a completely isolated Unity 2022 buyer project already containing the separate original Animator Contract Audit produced `CS0234` at `HprInputReadinessAudit.cs:10`: `UnityEditor.Build.Profile` does not exist in that Editor generation. Unity exited with failure. The private failure log is `/data/var/marketplace-account-setup/unity-input-audit-unity2022-20261120-night/oldinput-native-import.unity.log`, and the source test/failure project was preserved. This is a verified original buyer-installation defect, not an inference from source.

The minimal patch conditionally imports that namespace and calls `BuildProfile.GetActiveBuildProfile()` only under `UNITY_6000_0_OR_NEWER`. Older Editors use their global Player input setting and explicitly report that Build Profiles are unavailable; Unity 6 retains the prior conservative active-profile override safeguard. No project settings, assets, package dependencies or existing reports are written by the product.

## Next release boundaries and market research

The Input System is now a Unity **core package** in Unity 6.7 and newer, versioned with the Editor rather than the old independent package series. Unity announced the core-package change and maintains a public explanation: https://docs.unity.com/en-us/engine/6000.7/manual/packages-list/packages-all/pack-core/com-unity-inputsystem and https://discussions.unity.com/t/planned-breaking-changes-in-unity-6-7/1723293/59 . A manifest-only `com.unity.inputsystem` presence check could wrongly classify core-package projects. **Unity 6.7/7.0 behavior is not tested in an installed matching Editor here.** Research and add a conservative diagnostic, without falsely claiming core-package presence, before advertising those versions as supported.

Current publisher and community discussions confirm actual legacy/new-input mismatch problems, including the July 2026 Unity 6.7 alpha lockup when old `GetKeyDown` calls produce continuous errors. A commenter also suggests checking Project Auditor, showing competition: https://discussions.unity.com/t/old-input-causes-lockup-6000-7-0a2/1731096 . The niche is genuine but selling a tiny checker independently has **no proven willingness to pay**. The original HPR Animator Audit may be bundled in a stronger first-party gameplay package as a quality tool only if independent buyer acceptance and licensing justify it.

All packages remain **internal, unpublished**. Normal graphical Editor screenshots remain blocked by the Unity Software Terms gate that the producer did not accept or bypass. Human UI acceptance, buyer onboarding, Unity Asset Store license/rights/pricing, source-publication economics, and seller approval remain release gates.
