# Third-party components and AI provenance

There is no embedded third-party source, purchased animation, icon, model,
audio, video, font, runtime module, package dependency or online service.
The tool invokes documented public Unity Editor APIs in the purchaser's
installed Unity Editor. Unity trademarks and APIs remain subject to Unity's
own terms.

AI-assisted source development and documentation were used. Native Editor
acceptance and product descriptions must truthfully disclose which actions,
tests, target versions and any AI-generated marketing material apply.
