# HPR Input Compatibility Audit — private candidate

An **Editor-only, read-only** diagnostic for Unity projects moving between the legacy Input Manager and the newer Input System package. Tested target: Unity 6.6.8f1; older editors/platforms still require independent validation.

Open **Tools → HPR → Input Compatibility Audit**. Choose **Scan input compatibility** to inspect project input settings, the input package manifest and C# runtime files under `Assets`. The tool reports source locations of **potential** legacy-input calls when the newer backend alone is enabled. It also flags absent or unknown configuration and source paths where it cannot make a certain decision. You may deliberately export a JSON report to a new file with **Export report**; no report is automatically written. Findings with source lines offer buttons that open the original script at the reported location only when you deliberately click them. The scanner never changes project settings, imports packages, converts scripts, deletes files or replaces existing reports.

The scanner also identifies a potential unguarded newer Input System API in legacy-only projects. When the *current Unity project* uses any custom active Build Profile, the tool deliberately reports `Unknown`/`ACTIVE_BUILD_PROFILE_OVERRIDE`: the global input setting may not be the effective Player mode. Inspect the active Build Profile and compile a real Player; the tool never silently assumes the global value applies. Findings are capped and a truncated audit is explicitly incomplete, not a pass. The scanner understands simple preprocessor guards using `ENABLE_INPUT_SYSTEM`, `ENABLE_LEGACY_INPUT_MANAGER` and `UNITY_EDITOR`. Conditional expressions it cannot establish are shown for manual review, not declared definitely active. Comments and ordinary source string literals are excluded from call matches, but this is **not a compiler or full C# syntax analyzer**. False negatives/positives are possible, including aliases, reflection, dynamic calls, more complex compiler defines, Scene `StandaloneInputModule` components and binary/embedded UPM packages. Large files and caps are reported. The tool does **not** promise that a built Player works: separately test the input system in Play Mode and an actual Player, including UI navigation and gameplay.

This build is an internal engineering candidate, **not an approved Asset Store release**. No distribution or seller terms are included; rights, store listing, manual accessibility and customer-user studies need separate review.
