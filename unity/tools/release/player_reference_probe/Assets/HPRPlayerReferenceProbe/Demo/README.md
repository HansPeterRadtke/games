# Original demonstration scene and sample assets — documentation

The demo contains a small, original first-party Unity scene with two physical display pedestals. It has one **assigned** sample prefab reference and one **intentionally empty** reference. The scene GameObject called **HPR | Reference Probe (select me)** holds the opt-in component. Open the demo scene in the Project panel, select this GameObject, and choose **Tools → HPR → Player Reference Probe**. Press **Inspect selected scene probe — read only** to inspect the original sample data in the Editor. Open the two ScriptableObject assets under `Demo/Resources/HPRSample` to inspect the assigned and empty object slots.

The demo uses `resourcesPath` to access those samples; its scene component deliberately holds **no direct ScriptableObject references**. Build and run the demo scene yourself to produce a true Player receipt. Export the Editor baseline first, run the built executable, and compare the two original JSON files in the Editor. Unity includes contents of `Resources` folders in Player builds, so this demo is a positive smoke test and an intentionally empty-field test; it is **not** a reproduction of a Unity engine bug. Testing a Player-only failure requires a distinct real target project where that behavior occurs; the sample does not simulate or manufacture customer defects.

All demo meshes are Unity's primitive geometry, with first-party materials generated in Unity. The demo doesn't use external images, fonts, models, textures, plugins, packages, or network operations. The sample ScriptableObject class is included solely to make the usage workflow reproducible. Remove the demo folder to exclude it from your project if not needed, while keeping `Runtime` and `Editor`. Neither the runtime component nor this demo automatically changes the user's other scenes or source assets.

The main `README.md` provides full setup instructions and limitations. This documentation is intended for local use without internet access.
