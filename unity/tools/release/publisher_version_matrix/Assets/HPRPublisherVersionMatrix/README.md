# HPR Publisher Version Matrix — private prototype

This original Editor-only Unity tool creates an evidence snapshot of an **already imported** first-party package in the current Unity Editor version. Use **Tools > HPR > Publisher Version Matrix**, enter one or more exact publisher-owned `Assets/...` root folders separated by semicolons, click **Scan imported package roots**, inspect the summary, and export a **new** JSON receipt. It never automatically imports, upgrades, modifies, resaves, or publishes source assets.

Repeat the scan in separately prepared, disposable Unity Editor projects (for example Unity 2022 and Unity six) containing the same exact `.unitypackage`, then choose **Tools > HPR > Compare Publisher Version Receipts**. Select the two saved JSON snapshots, inspect the result list, filter to an affected asset, and optionally export a **new** JSON difference report. This comparison runs entirely within the Unity Editor using the included original C# sources, without Python or another dependency. The separate `qa/compare_version_receipts.py` script is private verification tooling and is not required by buyers. The report records real imported asset paths, Unity GUIDs and direct AssetDatabase dependencies, and marks missing paths or unscannable folders as INCOMPLETE. Mismatched source GUID identities and dependencies are flagged by the comparison. It is not a binary compatibility guarantee: references absent from Unity's dependency graph, gameplay behavior, serialized field values, type remapping, Play Mode, player builds and pipeline visuals require separate native tests.

The full developer sources are included. No external account, network access, background service, custom runtime assembly, package dependencies, or renderer setting is required. The code is limited to public UnityEditor APIs. The export uses exclusive file creation to avoid overwriting prior audits. This project is **not** cleared for sale.
