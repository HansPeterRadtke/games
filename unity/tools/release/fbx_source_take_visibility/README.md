# HPR FBX Source Take Visibility — separate unpublished Editor product candidate

This is a **new**, original read-only Unity Editor tool, not a replacement
for FBX Clip Identity Audit, which checks repeated animation local IDs.
**Important commercial evidence:** Unity 6000.4.3f1, 6000.5.0b4 and
6000.6.0a2 already added a native information message and Import Unreferenced
Takes button for a single FBX. The remaining potential benefit is bulk
project-wide read-only scanning; this is a low-priority candidate feature,
NOT a justified independent paid listing.

The first-party buyer content is exclusively in
`Assets/HPRFbxSourceTakes/`, with two Editor C# files, concise buyer
instructions, a rights-review placeholder and two first-party axis-baked Blender FBX examples with verified native normal
mesh orientation and scale, two genuine Editor-generated prefabs
and one actual Unity scene for first-use orientation: the normal model and
a deliberately incomplete custom Animation tab model. Both samples are excluded from customer-project
scan results so new empty buyer projects do not get false clean passes.

Private `qa/` contains the Blender original-source generator, genuine
native author/independent buyer import tests, deliberately customized
private FBX fixtures, original one-to-two-action source-reexport tests,
fixed-scope `.unitypackage` identity verifier and an optional offline
official Asset Store Tools runner. **Never package `qa/`**, synthetic
negative fixtures, raw logs, original recordings or other vendor models.

Native supported installed Editor generations for QA are Unity 2022.3.22f1
and Unity 6000.6.8f1. Every run takes a new unique private owner
repro directory and refuses overwrites. The product itself cannot repair
missing clips, guarantee source take compatibility, edit project settings,
contact publishers or upload data. The CI/preflight candidate is not
licensed or cleared for public release; true screenshots, consent, platform
eligibility, market demand and publisher submission are independent gates.

Developer/market evidence and actual release acceptance are documented in
`doc/unity-product-research-2026-10-31/fbx-source-take-visibility-2026-11-22.md`.
