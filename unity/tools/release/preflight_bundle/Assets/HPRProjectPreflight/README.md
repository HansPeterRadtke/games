# HPR Project Preflight — internal combined Editor bundle

This bundle combines two *original, read-only* HPR Editor audits in one installation and adds a small one-window preflight workflow. Open **Tools > HPR > Project Preflight Bundle**, then choose **Run Input + Animator audits (read only)**. The tool summarizes potential legacy/new Input System mismatches and Animator Controller transition, state and Blend Tree parameter-contract problems. You can open either detailed auditor directly. You may also explicitly export one combined JSON report to a **new** file; an existing file cannot be overwritten.

The package contains only three namespaced vendor folders: `Assets/HPRInputReadiness/`, `Assets/HPRAnimatorContract/`, and `Assets/HPRProjectPreflight/`. The scripts are **Editor-only**, and the default audit does not write assets, edit Player Settings, install packages, modify Animator Controllers, or upload files. Independent descriptions and limitations are in the Input and Animator folders' READMEs. This bundle does not fix code or guarantee animation/runtime correctness. Results may be incomplete and must be interpreted with the two scanners' limits.
